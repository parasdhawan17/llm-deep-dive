MODULE 6

Open vs Closed and Deployment

This module compares open and closed models. You will learn what "open" really means. You will learn how to run models yourself. You will learn how to choose between build and buy.

Lesson 6.1

Open weights vs API models

Open weights means you can download the model files. You run them on your own computers. An API model runs on the provider's computers. You send requests over the internet.

Open-weight examples are Llama, DeepSeek, and Mistral. API examples are GPT, Claude, and Gemini.

Licenses

The license tells you what you may do. Some licenses are fully open. Some licenses limit commercial use. Read the license before you use the model.

TopicOpen weightsAPI model
ControlFullLimited
PrivacyData stays with youData goes to the provider
CostHardware plus skillPay per token
UpdatesYou updateThe provider updates
Skill neededHighLow
Note: "Open" does not always mean fully free. The license decides what you may do.

Lesson 6.2

Run models yourself

VRAM is memory on the graphics card. Model weights live in VRAM during use.

memory = parameters x bytes per parameter

For example, a widely used 8-billion-parameter model in INT4 needs about 4 to 5 GB.

Formats

  • GGUF is a format for CPU use.
  • AWQ and GPTQ are formats for GPU use.
  • All three shrink the model with quantization.

Tools

  • Ollama runs models on your laptop with one command. It is the simplest start.
  • vLLM serves many users at high speed. Use it for production APIs.

Five steps to your first local run

  1. Choose a model and a format for your hardware.
  2. Check VRAM with the math above.
  3. Install Ollama or vLLM.
  4. Download the model files.
  5. Test with a simple prompt.
Note: Start on CPU with a small GGUF model. Move to GPU only when you need more speed.

Lesson 6.3

The build-vs-buy decision

Build means you self-host open weights. Buy means you pay for an API.

FactorBuild fits whenBuy fits when
Team skillYou have ML engineersYou have app developers only
Data privacyStrict rules forbid outside data flowNormal rules allow it
ScaleVery high volume, steady loadVaried or low volume
Latency needsYou control the serversProvider speed is enough
Cost shapeFixed hardware cost is fineYou prefer pay per token

License limits

Some licenses forbid training rival models on outputs. Some require you to show the model name. Check these rules with your legal team.

Note: Most teams start with buy. They move to build when volume or privacy demands it.
